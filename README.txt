MY LIFE PLANNER - prototipo web per iPhone
1. Estrai lo ZIP.
2. Carica la cartella su un hosting HTTPS come Netlify o GitHub Pages.
3. Apri l'indirizzo in Safari su iPhone, tocca Condividi > Aggiungi alla schermata Home.
I dati sono salvati localmente nel browser sul dispositivo; cancellare i dati del sito può eliminarli.
Questa versione NON include notifiche push, sincronizzazione cloud, calendario mensile grafico o acquisti in-app. Non è ancora un pacchetto pronto per App Store.
